# Arena Digital portfolio

Repository indipendente dal gestionale F.P.S. che lo contiene sul disco. Contiene la vetrina statica Arena Digital e i collegamenti alle quattro applicazioni demo originali, il cui codice resta in un repository privato separato.

- Comunica in italiano semplice. TypeScript strict, React, Vite, sorgenti Prettier.
- Il 7 novembre 2026 l'utente ha autorizzato i repository `Francehws/arena-digital-portfolio` pubblico e `Francehws/arena-digital-demos` privato, le quattro demo pubbliche e l'uso di codice, interfacce, marchi e materiali. Non estendere il consenso ad altri prodotti.
- Nel repository pubblico non includere backend, dati, credenziali o cronologie dei clienti. Sono approvate soltanto le quattro anteprime native selezionate e i materiali della vetrina.
- Nessun backend o database in LocalStorage nella vetrina. Le demo esterne usano esclusivamente ambienti separati e dati fittizi; nessuna integrazione produttiva.
- Telefonate, messaggi, prenotazioni e pagamenti sono simulati: dichiararlo sempre.
- Per verificare: npm run typecheck; npm test; npm run build; npm run test:browser; npm run check:secrets.
- Report interni, inventari, marketing e output QA sono esclusi dal repository pubblico.
- Pubblicazione e push nel perimetro indicato sono autorizzati; ottenere approvazione prima di ampliare contenuti, destinazioni o costi. Usare solo servizi gratuiti, senza upgrade automatici.
- Non inserire licenza open source senza autorizzazione. Nessun recapito inventato.
